# Фронтенд приложение (Nuxt 3 + TypeScript + FSD)

Реализация интерфейса в соответствии с ТЗ и методологией Feature-Driven Design.

## Стек технологий
- **Framework:** Nuxt 3 (Vue 3)
- **Language:** TypeScript
- **Styles:** SCSS + БЭМ
- **Architecture:** FSD (с заменой `/shared` на `/common`)
- **Code Style:** ESLint + Prettier

## Инструкция по запуску

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```
Приложение будет доступно по адресу: http://localhost:3000

3. Проверка кода линтером:
```bash
npm run lint
```
